# Methodology

Freeze prompts, hypotheses, outcome definitions, exclusions, configurations, and analysis before gathering confirmatory data. Use fictional entities to isolate experimentally supplied cues. Add real-entity studies to assess external validity under separate protocols.

Counterbalance candidate order and exposure assignment. Use fresh sessions, pin model identifiers where possible, and record settings, observation times, raw responses, abstentions, and failures. Treat prompt families or entity pairs as blocks in confirmatory analysis. A single pilot run gives a descriptive effect estimate.

Publish the protocol, data provenance, analysis, and deviations alongside results where redistribution is permitted. Report null and adverse effects, and document any commercial conflicts.
