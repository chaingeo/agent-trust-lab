# Theoretical Framework

The observable outcome is entity selection for a particular task. A decision combines the agent configuration, candidate set, task requirements, retrieved evidence, and interaction history.

Familiarity describes prior exposure. Trustworthiness describes evidence about an entity's ability and reliability for the task. Endorsement independence, provenance, recency, and verified outcomes are separately manipulable signals.

Study candidate retrieval separately from selection among fixed candidates. Retrieval determines which options are visible. Selection determines what happens after those options are visible. Report configuration and access constraints for each stage.
